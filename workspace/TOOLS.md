# TOOLS.md — Local Notes

Use this file for environment-specific details that should not live in shared skills or generic docs.

Security note:
- Do not store secrets here, including API keys, auth tokens, or passwords.
- Do not store private URLs that embed credentials.
- Avoid personal or identifying user data here; use safer workspace docs or platform-managed secrets instead.

Examples:
- preferred TTS voice
- kitchen device names
- speaker or room names
- local API endpoints
- hardware notes for embedded clients
- webhook endpoints for kitchen workflows

Keep it practical and specific.
